# 🐾 HAUSTER

**Sistema de gerenciamento para Pet Shops**

O **HAUSTER** é um sistema desenvolvido para auxiliar na gestão de pet shops, centralizando informações e facilitando o controle das principais atividades do estabelecimento.

A plataforma foi pensada para tornar a administração do pet shop mais **organizada, prática e eficiente**, reunindo ferramentas para gerenciamento de produtos, estoque, serviços, funcionários, vendas e informações financeiras.

---

## 📌 Sobre o projeto

O HAUSTER surgiu a partir da necessidade de oferecer uma solução simples e prática para problemas comuns na gestão de pet shops.

Com o sistema, é possível centralizar diferentes áreas da administração em uma única plataforma, facilitando o controle e a organização das informações do estabelecimento.

### Principais áreas:

* 📅 Agendamento e gerenciamento de serviços
* 📦 Controle de produtos e estoque
* ✂️ Gerenciamento de serviços
* 💰 Controle financeiro
* 📊 Acompanhamento de vendas e receitas
* 👥 Gerenciamento de funcionários
* 🔐 Controle de usuários e permissões

## 💻 Como executar o projeto

### Pré-requisitos

Para executar o HAUSTER localmente, é necessário ter:

* [XAMPP](https://www.apachefriends.org/)
* PHP
* MySQL
* Um navegador web

### Instalação

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/hauster.git
```

2. Coloque o projeto na pasta `htdocs` do XAMPP:

```text
C:\xampp\htdocs\hauster
```

3. Inicie o **Apache** e o **MySQL** pelo XAMPP.

4. Crie o banco de dados utilizado pelo projeto.

5. Configure a conexão do sistema com o banco de dados.

6. Acesse o projeto pelo navegador:

```text
http://localhost/hauster
```
